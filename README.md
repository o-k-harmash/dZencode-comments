# Комментарии с каскадным списком

## ▶️ Запуск и требования

### Требования

- **ОС**: Windows или Linux (Docker установлен и работает)
- **Git**: для клонирования репозитория
- **Docker + Docker Compose**: для сборки и запуска контейнеров
- **.NET SDK** (опционально, если запускать без контейнеров)

---

### Инструкция запуска

1. Клонировать репозиторий:

```bash
git clone https://github.com/o-k-harmash/dZencode-comments.git
cd dZencode-comments
```

2. Запустить сборку и контейнеры:

```bash
docker-compose up --build
```

3. После запуска:
- Фронтенд доступен по адресу http://localhost:8000
- Бэкенд API доступен по адресу http://localhost:8001
- Pgadmin по адресу http://localhost:5050

### Если .NET проект не билдится

Иногда при локальной сборке мешают артефакты компиляции.  
Попробуйте удалить папки `bin` и `obj`.

Также возможны ошибки при первом запуске контейнеров.  
Важно, чтобы сервисы стартовали в правильном порядке, но настройка healthcheck не проводилась.  
В таком случае попробуйте перезапустить сборку несколько раз.

## 🧩 Архитектура

### Фронтенд: client (React)

**Важно:** любые операции не имеют никаких прав доступа или идентификации отправителя.

Представляет из себя клиентский интерфейс. Реализовано в рамках пользовательской истории просмотр, добавление и удаление комментариев.

Пользователь появляется на основной странице комментариев, где можно получить по фильтрам верхнеуровневые комментарии к абстрактному ресурсу (не имеющие родительского комментария).  
Фильтрация включает:
- сортировку по времени добавления (в порядке убывания или возрастания),
- параметры пагинации (5, 10, 15, 20, 25 элементов).

Пользователь видит форму создания комментария верхнего уровня и список отфильтрованных комментариев.  
Каждый узел запрашивает комментарии (ответы) отдельно по намерению пользователя (для простоты — первые 25 ответов без полноценной пагинации).

Каждый комментарий верхнего уровня — карточка с метаинформацией:
- пользователь,
- аватар,
- дата,
- количество лайков (не реализовано),
- тело комментария,
- нижний борд для просмотра ответов (по `parentId`), создания ответа или удаления текущего комментария.  
**Удаление не является каскадным и не приводит к удалению ответов в базе данных.**

---

#### Архитектура интерфейса

Состоит из классических React‑паттернов: каждый компонент является состоянием, вью‑моделью и контроллером с data‑binding.  
Архитектура не оптимизирована академически: управление состояниями децентрализовано, синхронизация через проброс колбеков.  
Перерисовка при изменении занимает предположительно `O(n * k)`, где `n` — число видимых узлов, `k` — глубина ветки.

---

#### Компоненты

- **ReplyForm** — простая форма ввода, инкапсулирует только разметку и реакции на ввод. Может быть расширена до текстового редактора. Получает состояние извне и вызывает внешние колбеки.
- **Comment** — одновременно узел и компонент комментария. Инкапсулирует управление собственным узлом: форма ответа и список дочерних комментариев (`parentId`). Для синхронизации вызывает колбеки вышележащих узлов, оповещая их об обновлении.
- **Comments** — страница, объединяющая список комментариев и форму добавления верхнеуровневого комментария.

---

## 🔧 Бекенд: api (ASP.NET Core)

Представляет из себя API доступа к комментариям, поддерживающий все CRUD‑операции по протоколу HTTP.

**Важно:** не имеет разделения по окружениям, CORS используется только в рамках тестовой системы, актуализация базы данных выполняется при запуске (для упрощения деплоя).

---

### 📂 Организация файлов

- **Features** — настройка эндпоинтов, модели данных и расширения.
- **Domain** — модели данных (не являются EF Core моделями).
- **Infrastructure/EFCoreEntityConfiguration** — конфигурации для EF Core.

---

### 🔹 Эндпоинты

#### Получить дерево комментариев

GET /api/comments

**Пример ответа:**

```json
{
"comments" :[
  {
    "id": "guid",
    "parentId": null,
    "nickname": "User123",
    "avatarUrl": "/avatars/u123.png",
    "text": "Первый комментарий",
    "timestamp": "2026-05-18T00:00:00Z",
    "replies": []
  }
],
"totalCount": 20,
"page": 1,
"limit": 5
}
```

### Создать комментарий

POST /api/comments

**Пример тела запроса:**

```json
  {
    "text": "Мой новый комментарий",
    "nickname": "User123",
    "avatarUrl": "/avatars/u123.png",
    "parentId": null
  }
```

### Получить комментарий по ID

GET /api/comments/{id}

### Удалить комментарий

DELETE /api/comments/{id}
